# Build configuration commands

**Set the build target to ESP32S3：**

```bash
idf.py set-target esp32s3
```

**Open menuconfig：**

```bash
idf.py menuconfig
```

**Select board：**

```
Xiaozhi Assistant -> Board Type -> `Movecall Moji 小智AI衍生版` (Movecall Moji XiaoZhi AI derivative)
```


**Build：**

```bash
idf.py build
```
