# Server restore checklist (2026-10-19 snapshot)

The xiaozhi-server code customizations live INSIDE the docker container
(ephemeral on recreate). This directory + the checklist below rebuild them.
Order matters: files first, then config, then restart.

## 1. Files (copy back with `docker cp`)

| Repo file | Container target |
|---|---|
| `server-patches/plugins/get_laptop_temp.py` | `/opt/xiaozhi-esp32-server/plugins_func/functions/get_laptop_temp.py` |
| `server-patches/asr/sherpa_onnx_local.py` | `/opt/xiaozhi-esp32-server/core/providers/asr/sherpa_onnx_local.py` |

What they do (English comments inside):
- `get_laptop_temp.py`: server plugin (Vietnamese description) that reads the
  laptop CPU temperature through the bridge sensor endpoint below.
- `sherpa_onnx_local.py`: upstream file + transducer branch (see `0004-*.patch`)
  + Vietnamese-English loanword fixups (`laptop`, `wifi`, `bluetooth`,
  `youtube`, `spotify`, `google`) applied after every recognition.

## 2. `data/.config.yaml` keys (edit by hand, NEVER commit the real file: it holds API keys)

```yaml
close_connection_no_voice_time: 10   # 10 s of silence closes the turn

VAD:
  SileroVAD:
    threshold: 0.6
    threshold_low: 0.3
    # min_silence_duration_ms: 1200  (see server default config; 200 ms upstream
    # chops natural breath pauses into 2-3 word fragments)

Intent:
  function_call:
    functions:
      - get_laptop_temp

end_prompt:
  enable: true
  prompt: |
    Tạm biệt sếp GỌN trong đúng 1 câu ngắn (dưới 12 chữ), ấm áp nhưng không dài dòng.
    Ví dụ: 'Em chào sếp, cần gì gọi em nhé!'
```

## 3. Secrets (REGENERATE, never stored here)

- `data/laptop_temp.json` (mode 600):
  `{"url": "http://192.168.1.40:8643/internal/laptop-temp", "token": "<fresh 32-hex>"}`
- LXC `/root/.hermes/laptop_temp_token` (mode 600): the SAME token value.
  Generate: `python3 -c "import secrets; print(secrets.token_hex(16))"`

## 4. Bridge (LXC `/root/hermes-robot-bridge/`)

Source of truth is `bridge/bridge.py` in this repo (synced copy).
Systemd unit template: `bridge/hermes-robot-bridge.service`.
Restart after sync: `systemctl restart hermes-robot-bridge`.

## 5. Hermes MCP laptop sensors (LXC `/root/hermes-mcp-laptop/server.py`)

Source of truth: `bridge/mcp-laptop-server.py` in this repo (copy back to
`/root/hermes-mcp-laptop/server.py`). Gateway `~/.hermes/config.yaml` entry:

```yaml
mcp_servers:
  laptop-sensors:
    command: /usr/local/lib/hermes-agent/venv/bin/python
    args: ["/root/hermes-mcp-laptop/server.py"]
    connect_timeout: 20.0
    enabled: true
```

Verify: `hermes mcp test laptop-sensors`.
NOTE: the running gateway only picks up new MCP servers after a restart, and
the gateway can NOT be restarted from inside its own session
(`hermes gateway restart` must run from a separate shell).

## 6. Restart + verify

```
docker restart xiaozhi-server
# expect: Up, 0 Traceback; robot reconnects; tool list contains get_laptop_temp
# voice check: "nhiệt độ laptop bao nhiêu" -> answers with a number
```
